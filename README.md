# 🌐 Axciller Portfolio  

A modern personal portfolio website built with **React, TypeScript, and Vite**, designed for my client.  
The website showcases projects, skills, and contact information with a sleek and responsive design.  

🔗 **Live Website:** [Axciller.vercel.app](https://Axciller.vercel.app)  

---

## 🚀 Tech Stack  

- ⚛️ React + TypeScript – Component-based frontend  
- ⚡ Vite – Lightning-fast bundler & dev environment  
- 🎨 Tailwind CSS – Modern utility-first styling   
- 🖼️ Lucide Icons – Minimal icon set  

---

## ✨ Features  

- Fully **responsive design** (desktop,  mobile)  
- **Optimized performance** with Vite + React  
- Smooth **animations and transitions**  
- Showcases **projects, skills, and contact details**  
- **SEO-friendly** and fast-loading pages
